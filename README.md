# Бот по уборке

Следит за мусором и ковриками, штрафует за просрочку и помнит, кто что покупал.

## Правила

| Что | Очередь | Когда | Без штрафа | Дальше |
|---|---|---|---|---|
| 🗑 Мусор | Никита → Артём → Дима | первый раз 5 ноября, потом через 4 дня после того, как предыдущий отметил | 1 день | 100 Kč в день |
| 🧺 Коврики | Артём → Дима → Никита | 29-го каждого месяца (в феврале последний день), первый раз 29 ноября | 2 дня | 100 Kč в день |
| 🛒 Продукты | следующим покупает тот, кто брал эту позицию реже всех | без сроков | — | — |

«Сделал» может нажать только тот, чья очередь. Штраф списывается, когда должник пишет `/paid`, а кто-то из двух других нажимает «Подтверждаю».

Напоминания приходят в общий чат утром и вечером: в день срока и каждый день, пока задачу не отметят.

## Как это крутится

Бот живёт на Vercel, база — Postgres (Neon) из вкладки Storage в проекте Vercel.

- Telegram сам присылает каждое сообщение и нажатие кнопки на `/api/webhook`, постоянно работающий процесс не нужен.
- Напоминания шлёт крон Vercel: `/api/morning` в 09:00 UTC и `/api/evening` в 20:00 UTC. По Праге это 10:00 и 21:00 зимой, 11:00 и 22:00 летом. На бесплатном тарифе Vercel крон срабатывает в любую минуту этого часа.
- Пуш в `main` выкатывается на Vercel сам, если в Vercel → Settings → Git подключено приложение GitHub к репозиторию. Иначе жми Redeploy в Vercel.

### Первая настройка

1. В проекте на Vercel: **Storage → Create Database → Neon**, регион Frankfurt, подключить к проекту. Vercel сам добавит `DATABASE_URL`.
2. **Settings → Environment Variables**: добавить `BOT_TOKEN` с токеном от @BotFather.
3. Передеплоить проект, потом один раз открыть `https://<проект>.vercel.app/api/setup`: он пропишет вебхук в Telegram и покажет, куда тот смотрит.
4. Создать группу с Димой и Артёмом, добавить туда бота и написать в группе `/start`. Каждый нажимает кнопку со своим именем.

Если Telegram превратил группу в супергруппу (так бывает после смены настроек), напиши `/start` в группе ещё раз.

## Локальный запуск

```bash
cd /Users/macbook/proga/bot_uborka
.venv/bin/python bot.py
```

Токен берётся из `.env`, база — файл `uborka.db`. Если папки `.venv` нет: `python3.13 -m venv .venv && .venv/bin/pip install -r requirements.txt`.

Локальный запуск отключает вебхук, и бот на Vercel перестаёт получать сообщения. После локальных опытов открой `/api/setup` ещё раз.

## Команды

- `/status` — чья очередь, сроки, долги и кнопки «сделал»
- `/shop` — кто следующий покупает каждую позицию и кнопки «купил»
- `/fines` — долги по штрафам
- `/paid` — «я заплатил», сосед подтверждает
- `/remind` — прислать напоминания прямо сейчас

## Тесты

```bash
.venv/bin/pip install pytest
.venv/bin/pytest
```

Чтобы прогнать тесты базы ещё и на Postgres, задай `TEST_DATABASE_URL` (тесты удаляют таблицы в этой базе, бери пустую).

Правила (кто, когда, сколько) лежат в `rules.py`, тексты наездов в `texts.py`.
